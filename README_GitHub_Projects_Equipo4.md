## Guía de publicación
1. Abrir [GitHub Projects de YahirZing](https://github.com/users/YahirZing/projects) y crear un proyecto nuevo de tipo Table.
2. Asignar el título indicado y agregar los campos anteriores.
3. Copiar los títulos desde `Titulos_para_pegar_en_GitHub_Projects.txt` para crear los 11 borradores.
4. Abrir cada borrador y pegar su descripción desde `issues/ACT-XX.md`; agregar responsable, fechas y prioridad.
5. Añadir una vista **Board** por `Estado` y una vista **Roadmap** con las dos fechas estimadas.
6. Verificar la distribución con los miembros del grupo y registrar los tiempos reales conforme se produzcan.

La cuenta conectada de GitHub permite gestionar issues en repositorios, pero no exponer actualmente la operación de creación de Projects. Este paquete es material preparado para su carga, no un proyecto ya publicado.
